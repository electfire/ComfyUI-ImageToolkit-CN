# 图像工具箱（ComfyUI 插件 · 全中文）

三个节点，覆盖「**批量导入 → 转换/压缩/缩放 → 批量导出**」的完整流程。
**不需要安装任何第三方依赖**，只用 ComfyUI 自带的 Pillow / numpy / torch。

安装位置：`ComfyUI\custom_nodes\ComfyUI-ImageToolkit-CN\`
安装后**重启 ComfyUI**，在节点菜单的 **「图像工具箱」** 分类下即可找到（也可直接双击画布搜索中文名）。

---

## 🖼️ 节点1：图像转换压缩

| 参数 | 说明 |
| --- | --- |
| 目标格式 | PNG / JPG / WEBP / BMP / GIF / TIFF 任意互转 |
| 压缩模式 | **按质量**：用下面的 0-100 滑块；**按体积**：自动找最高画质压进目标体积 |
| 质量 | 0-100 滑块。JPG/WEBP 直接控画质；PNG 会换算成压缩级别；BMP/GIF/TIFF 无损，此项无效 |
| 目标体积KB | 「按体积」模式下每张图的大小上限 |
| 体积超标处理 | 质量降到最低仍超标时，是否允许逐步缩小分辨率（每次 85%，最多 6 次） |
| 缩放方式 | 不缩放 / 指定宽高 / 按长边 / 按短边 / 按百分比 |
| 指定宽度·高度 | 仅「指定宽高」生效：等比缩放后完整放进该框内，**不会拉伸变形** |
| 长边像素 / 短边像素 / 缩放百分比 | 分别只在对应方式下生效 |
| 缩放算法 | LANCZOS（缩图最锐利）/ BICUBIC / BILINEAR / NEAREST |
| 尺寸对齐 | 把最终宽高向下取整到 2/8/16/32/64 的倍数，方便后续送模型 |

- **五种缩放方式各自独立**：切换方式时只读取该方式对应的参数，互不影响；界面上也会自动隐藏当前用不到的参数。
- **单图可用**：直接把「加载图像」等任意标准图像节点接到 `image` 输入口。
- **批量可用**：接「图像批量加载」的 `图像列表` 输入口，整批一次性处理。
- 输出 `图像列表`，可直接连到「图像批量保存」。

## 📂 节点2：图像批量加载

| 参数 | 说明 |
| --- | --- |
| 目录来源 | 下拉列出 ComfyUI `input` 目录及其一级子文件夹；选最后一项可自定义路径 |
| 自定义路径 | 任意绝对路径，如 `D:\照片\测试`（也支持相对 input 的路径） |
| 包含子文件夹 | 递归读取所有子目录 |
| 文件扩展名 | 逗号分隔，如 `png,jpg,webp`；留空=全部图片 |
| 排序方式 | 文件名升/降序、修改时间新→旧/旧→新、文件大小的→小/小→大 |
| 起始索引 / 加载数量 | 切片读取；加载数量填 0 表示全部 |

- 自动纠正 EXIF 旋转；透明通道合成到白底；GIF/TIFF 只取第一帧。
- **保留每张图的原始尺寸**（不会被强行统一），原始文件名也会一路带到保存节点。
- 文件夹内容有变动时会自动重新加载，不会用到旧缓存。
- 新建文件夹后，在网页上点一下**刷新**，新目录就会出现在下拉列表里。

## 💾 节点3：图像批量保存

| 参数 | 说明 |
| --- | --- |
| 保存方式 | **每次执行后自动保存**（默认）：工作流每跑一次就往 `output` 落盘一次；**仅执行（不自动保存）**：只执行并记住结果，之后点按钮再落盘。**节点上的「保存当前结果」按钮**：点击立即把上次执行的结果保存到 `output`，不重跑工作流，可反复点、随时点 |
| 子文件夹名称 | 在 `output` 目录下创建的文件夹名 |
| 文件夹策略 | 自动新建（重名加 `_1`/`_2`）/ 自动新建（加时间戳）/ 固定文件夹 |
| 文件命名 | 保持原文件名 / 自定义前缀+序号 / 自定义前缀+原文件名 / 纯序号 |
| 自定义前缀 · 序号起始 · 序号位数 | 命名细节，位数 4 即 `0001` |
| 输出格式 | **跟随上游**（推荐，直接落盘节点1 已编码好的结果）/ 也可强行指定其它格式 |
| 质量 | 仅在本节点需要重新编码时生效 |
| 同名文件处理 | 覆盖 / 自动加序号 |
| 保留工作流信息 | 保留（默认）/ 不保留，见下方说明 |

- **「保存当前结果」按钮**是即时保存：点一下就把最近一次执行的结果落盘到 `output`，完全不经过队列、不会重跑上游。重复点击会按「文件夹策略」继续新建文件夹（或按「同名文件处理」追加 `_1`、`_2`），不会误覆盖。
- **保存记录面板**（按钮下方的常驻区域，方案 B）：
  - 每次保存（含每次执行后的自动保存）都会记一行：`时间 · 张数 · 文件名 · 目标文件夹`，最近 5 条。文件名取该次保存的第一个文件（不带扩展名）。
  - **点击任意一行，打开该次保存的图片缩略图弹层**；再点缩略图即在新标签页看原图。记录随工作流保存，重开 ComfyUI 也在。
  - 面板是节点上的一个常驻控件，位置固定在「保存当前结果」按钮下方；节点显示输出图片预览时，预览图排在面板下面，不会把面板挤跑、也不会让节点一直变高。
  - 除「保存方式」外的保存参数默认折叠收起；点面板右上角的「显示参数 ▾」，或在节点上右键选「展开保存参数」，即可展开修改，改完再折回去。折叠状态同样随工作流保存。
- 暂存结果放在 ComfyUI 临时目录，重启后自动清理；点保存按钮时若暂存已过期，会提示重新运行。
- 也可以直接接标准 `IMAGE`（比如采样器输出），此时会按「输出格式」或 PNG 兜底保存。
- 保存后在节点上显示缩略图预览，并输出 `保存目录`、`保存数量`。

### 保留工作流信息

保存时把当前工作流的节点、连线、参数一起写进图片文件，**方便以后把图片拖回 ComfyUI 还原整条工作流**。

- 用**字节级注入**实现，不重新编码像素，**画质零损失**。
- 各格式的存放位置：

| 格式 | 存放方式 | 备注 |
| --- | --- | --- |
| PNG | `tEXt` 数据块（`workflow` / `prompt`） | 与 ComfyUI 官方 SaveImage 完全一致，拖回 ComfyUI 可直接还原 |
| JPG | COM 注释段 | 超长自动拆成多段 |
| WEBP | RIFF 的 XMP 块 | 追加在文件末尾，不影响图像块 |
| GIF | Comment Extension | |
| TIFF | ImageDescription 标签 | |
| BMP | 不支持 | 格式本身没有放元数据的位置，自动跳过并在节点上提示 |

- 元数据按 PNG 规范统一转义成 ASCII（同 ComfyUI 官方做法），中文节点名不会乱码。
- 不需要就选「不保留」，文件体积更小。

## 典型工作流

```
📂 图像批量加载  →  🖼️ 图像转换压缩  →  💾 图像批量保存
```

单图用法：

```
加载图像  →  🖼️ 图像转换压缩  →  💾 图像批量保存
```

只做格式转换不改尺寸：`缩放方式 = 不缩放`，只调 `目标格式`。
只想压到每张 100KB 以内：`压缩模式 = 按体积`，`目标体积KB = 100`。
统一处理成 webp 且长边 1024：`目标格式 = WEBP`，`缩放方式 = 按长边`，`长边像素 = 1024`。

## 节点尺寸锁定

- **手动拖过一次就锁死**：宽度和高度一起固定，重新加载 / 切换工作流 / 切换参数模式都不再变化，
  **除非你再次手动拖动节点边缘**。
- 锁定值写在节点的 `properties` 里，**随工作流一起保存**，换台电脑打开也还是这个尺寸。
- 锁死后切换「压缩模式 / 缩放方式」导致参数变少时，节点高度**不会缩回**；
  只有内容真的放不下时才会长高一点（保证参数不被截断）。
- 没手动调过的节点：宽度沿用工作流保存值，高度跟随参数自动贴合，切换模式时该长该收照常。
- 新拖出的同类型节点会沿用上次锁定的尺寸。
- 想回到自动尺寸：节点上**右键 → 「解除尺寸锁定（恢复自动尺寸）」**。
- 历史工作流里被旧版本撑大的高度，用新版本打开一次就会自动收回。

## 常见问题

- **下拉里看不到我的文件夹？** 用「📁 自定义路径」填绝对路径，或在网页点刷新后重新选择。
- **BMP/TIFF 为什么压不动？** 这俩是无损格式，本身不带画质参数；要小体积请选 JPG 或 WEBP。
- **GIF 输出颜色变少了？** GIF 只支持 256 色调色板，这是格式限制。
- **透明 PNG 转 JPG 后背景变白？** JPG 不支持透明通道，本插件统一垫白底（不会变黑）。
